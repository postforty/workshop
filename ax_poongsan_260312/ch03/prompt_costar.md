## 🚀 CO-STAR 프롬프트 프레임워크

**CO-STAR**는 싱가포르 정부 기술청(GovTech)의 데이터 과학 팀이 주최한 **프롬프트 엔지니어링 대회에서 우승**한 혁신적인 프레임워크입니다. 거대 언어 모델(LLM)로부터 더 정확하고 구체적인 응답을 얻기 위해 프롬프트의 주요 원칙들을 6가지 핵심 요소로 체계화한 것이 특징입니다.

---

### 📌 CO-STAR의 6가지 핵심 요소

| 요소 | 설명 | 목적 |
| :---: | :--- | :--- |
| **(C)ontext** | **맥락** | 작업의 배경 정보를 제공하여 AI가 상황을 정확히 이해하도록 합니다. |
| **(O)bjective** | **목표** | AI가 수행해야 할 구체적인 임무와 도달해야 할 최종 목적을 정의합니다. |
| **(S)tyle** | **스타일** | 답변의 문체나 필체(예: 비즈니스 전문가, 작가, 프로그래머)를 지정합니다. |
| **(T)one** | **톤** | 응답에서 느껴지는 감정이나 분위기(예: 전문적, 친근함, 냉철함)를 설정합니다. |
| **(A)udience** | **청중** | 응답을 읽거나 듣는 대상의 수준과 기대를 명시하여 어휘와 깊이를 조절합니다. |
| **(R)esponse** | **응답 형식** | 출력물의 형태(예: 표, 리스트, JSON, 마크다운 코드)를 지정합니다. |

---

### 💡 실전 활용 예시

#### 1️⃣ 비즈니스 마케팅 (이메일 작성)
> **상황:** 새로운 건강 기능 식품을 홍보해야 할 때

```text
Context: 우리는 3040 직장인을 위한 고함량 비타민 '에너지 부스트'를 출시할 예정이야.
Objective: 잠재 고객들에게 제품의 효능을 알리고 구매 사이트 방문을 유도하는 이메일을 작성해줘.
Style: 애플의 마케팅 전략처럼 간결하면서도 혁신적인 느낌으로 문구를 작성해줘.
Tone: 신뢰감이 있으면서도 에너지가 넘치고 활기찬 톤을 유지해줘.
Audience: 매일 피로를 느끼지만 바쁜 일상 때문에 건강 관리가 힘든 30대 후반 직장인들.
Response: 매력적인 이메일 제목과 본문, 그리고 마지막에는 클릭을 유도하는 버튼(CTA) 문구를 포함해줘.
```

#### 2️⃣ 교육 및 지식 전달 (블로그 포스팅)
> **상황:** AI와 교육에 관한 심층 분석 글을 작성할 때

```text
Context: 블로그 주제는 'AI가 현대 교육 시스템에 미치는 영향'이야.
Objective: 독자들이 AI 도입의 긍정적 측면뿐만 아니라 윤리적 고려 사항도 이해하도록 돕는 글을 써줘.
Style: 학술적이면서도 이해하기 쉬운 전문적인 논평 스타일.
Tone: 객관적이고 정보 중심적이며, 신뢰감을 주는 격식 있는 톤.
Audience: 대학 교수, 교육 정책 입안자, 그리고 교육 공학에 관심 있는 대학원생.
Response: 도입부-본문-결론의 형식을 갖춘 1,000자 이상의 마크다운 문서로 작성해줘.
```

#### 3️⃣ 기술적 작업 (웹 개발 예시)
> **상황:** Vue 3를 사용하여 특정 기능을 구현해야 할 때

```text
Context: Vue 3(Vite, TypeScript) 환경에서 Composition API를 사용해 웹사이트를 구축 중이야.
Objective: 로그인 후 대시보드 화면으로 이동하는 로직과 Pinia를 활용한 사용자 정보 상태 관리를 구현해줘.
Style: Vue 스타일 가이드를 준수하며 실무에서 사용되는 클린 코드 스타일.
Tone: 불필요한 사설 없이 코드와 주석 중심의 실용적이고 기술적인 설명.
Audience: Vue.js 구조는 이해하고 있지만 상태 관리 라이브러리(Pinia) 적용에 익숙하지 않은 시니어 개발자.
Response: 설명은 최소화하고, 즉시 복사해서 사용할 수 있는 `.vue` 파일 코드와 `store` 정의 코드를 분리해서 제공해줘.
```

### 🌟 CO-STAR가 효과적인 이유
단순히 "글 써줘"라고 요청하는 것보다 CO-STAR 형식을 따르면 AI는 **제한된 범위 내에서 가장 적절한 지식 데이터만을 필터링**하여 답변을 구성합니다. 이는 할루시네이션(환각 현상)을 줄이고, 사용자가 원하는 아웃풋에 한 번에 도달할 확률을 비약적으로 높여줍니다.
