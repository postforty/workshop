# 마크다운(Markdown) 기초 및 실습 가이드

마크다운(Markdown)은 텍스트 기반의 가벼운 마크업 언어입니다. 복잡한 서식 메뉴를 클릭할 필요 없이, 몇 가지 간단한 기호만으로 문서를 구조화하고 꾸밀 수 있습니다. 특히 **개발자 문서**, **블로그 포스팅**, 그리고 **AI와의 소통**에서 표준처럼 사용됩니다.

---

## 1. 왜 마크다운을 배워야 할까요?
1.  **간결함**: 쓰기 쉽고 읽기 쉽습니다.
2.  **호환성**: GitHub, Notion, Discord, Slack, ChatGPT/Gemini 등 대부분의 플랫폼에서 지원합니다.
3.  **AI 친화적**: AI는 복잡한 워드 프로세서 파일보다 구조화된 마크다운 텍스트를 훨씬 더 잘 이해하고 생성합니다.

---

## 2. 핵심 문법 (Cheatsheet)

### 2.1 제목 (Headers)
샵(`#`)의 개수로 제목의 수준을 정합니다.
```markdown
# 제목 1 (가장 큰 제목)
## 제목 2
### 제목 3
#### 제목 4
```

### 2.2 강조 (Emphasis)
텍스트를 굵게 하거나 기울일 수 있습니다.
```markdown
**굵게 강조할 텍스트** (앞뒤로 별 두 개)
*기울임 텍스트* (앞뒤로 별 한 개)
~~취소선~~ (앞뒤로 물결 두 개)
```

### 2.3 목록 (Lists)
순서가 없는 목록과 있는 목록을 만듭니다.
```markdown
- 순서 없는 항목 1
- 순서 없는 항목 2
  - 들여쓰기된 하위 항목 (스페이스 2칸)

1. 첫 번째
2. 두 번째
3. 세 번째
```

### 2.4 링크와 이미지
```markdown
[표시할 텍스트](https://www.google.com)

![이미지 설명(대체 텍스트)](이미지_주소.jpg)
```

### 2.5 코드 블럭 (Code Blocks)
코드나 명령어를 강조할 때 백틱(`` ` ``) 세 개를 사용합니다. 옆에 언어 이름을 쓰면 색상 강조(Syntax Highlighting)도 됩니다.

<pre>
```python
print("Hello, World!")
```
</pre>

### 2.6 인용구 (Blockquotes)
다른 사람의 말을 인용하거나 강조된 박스를 만들 때 사용합니다.
```markdown
> 마크다운은 정말 편리합니다.
> 이렇게 여러 줄을 쓸 수도 있어요.
```

## 3. 마크다운 실습 미션 🎯

아래 [**실습 원본 텍스트**]를 복사해서 마크다운 편집기(VS Code 등)에 붙여넣고, 지시사항에 따라 마크다운 문법을 적용해 보세요.

### [실습 원본 텍스트]
(아래 내용을 복사해서 수정해보세요)

나의 마크다운 연습

자기 소개
안녕하세요. 저는 AI 활용 능력 향상 과정을 수강 중인 홍길동입니다.

좋아하는 음식
피자
치킨
떡볶이

배우고 싶은 기술
프롬프트 엔지니어링
파이썬 기초
데이터 분석

오늘의 다짐
매일 30분씩 꾸준히 연습하자!

### [지시 사항]
1. "나의 마크다운 연습"을 **제목 1 (#)**로 바꾸세요.
2. "자기 소개", "좋아하는 음식", "배우고 싶은 기술", "오늘의 다짐"을 **제목 2 (##)**로 바꾸세요.
3. "홍길동"을 **굵게(**)** 처리하세요.
4. 좋아하는 음식 3가지를 **순서 없는 목록(-)**으로 만드세요.
5. 배우고 싶은 기술 3가지를 **순서 있는 목록(1. 2. 3.)**으로 만드세요.
6. 맨 마지막 문장("매일 30분씩...")을 **인용구(>)**로 감싸주세요.

---

## 4. 팁 (Tip)
*   **VS Code**: 확장 프로그램 없이도 `.md` 파일을 열고 우측 상단의 '미리보기(Preview)' 아이콘을 누르면 렌더링된 화면을 볼 수 있습니다.
*   **구분선**: `---` 를 입력하면 가로 구분선이 생겨 내용을 끊어줄 때 유용합니다.
*   **참고 사이트**: [Markdown Guide](https://www.markdownguide.org/)
