## 구글 제미나이(Gemini) 핵심 기능

### 1. 제미나이 기본 정보 및 활용 환경

*   **최신 모델 체계:** 
    *   **Gemini 3:** 구글의 가장 지능적인 모델로, 복잡한 추론과 문맥 이해 능력이 극대화됨.
    *   **Gemini 3 Flash:** 빠른 속도와 효율성을 갖춘 기본 모델로, 시각 처리와 코딩 에이전트 기능이 강화됨.
*   **서비스 통합:** 기존 Gemini Advanced가 **Google AI Pro** 및 **Google AI Ultra**로 통합/개편되어, 최대 200만 토큰의 컨텍스트 창과 최신 실험용 모델(Gemini 2.5 Pro 등)을 제공함.
*   **접근성:** 구글 계정만 있다면 별도의 설치 없이 브라우저나 모바일 앱을 통해 즉시 사용 가능.

### 2. 개인별 맞춤 AI (시스템 메시지 설정)

```text
모든 답변은 반드시 한국어를 사용합니다.
```

```text
답변을 생성할때는 분석적이고 냉철해야합니다.
```

```text
마크다운(Markdown) 작성 규칙은 다음과 같습니다: 1. 렌더링 안정성 확보: 볼드체(**)를 사용할 때 괄호(())나 대괄호([])와 붙어 있으면 렌더링 오류가 발생할 수 있으므로, [**텍스트**]처럼 기호를 안쪽으로 넣거나 **텍스트** (Text)처럼 공백을 두어 작성한다. 2. 표(Table) 가독성: 표 내부의 예시가 길어질 경우 <br> 태그를 적절히 활용하여 행의 높이를 조절한다. 3. 구조화: 헤더(H1~H3)를 계층적으로 사용하여 가독성을 높인다.
```

### 3. 제미나이 주요 활용 기능

제미나이는 구글 생태계와의 깊은 연동 및 자율 검색 기능을 통해 차별화된 효율성을 제공한다.

| 구분 | 주요 기능 | 상세 내용 |
| :--- | :--- | :--- |
| **자율 조사** | **Deep Research** | 복잡한 주제에 대해 스스로 수십 개의 웹 소스를 탐색하고 분석하여, **멀티 페이지 분량의 종합 보고서**를 작성해 주는 에이전트 기능이다. |
| **미디어 분석** | **유튜브 영상 요약** | 유튜브 링크를 분석하여 타임라인별 핵심 내용을 요약해 주며, 영상 시청 시간을 대폭 절약할 수 있다. |
| **협업 도구** | **Canvas** | 문서 작성 및 코딩을 위해 제공되는 **별도의 협업 공간**으로, AI와 실시간으로 내용을 수정하고 결과물을 다듬을 수 있다. |
| **청각화** | **Audio Overviews** | 업로드한 문서나 자료를 **팟캐스트 스타일의 대화형 오디오**로 변환하여 귀로 들으며 학습할 수 있게 한다. |
| **워크스페이스** | **@서비스 연동** | `@Gmail`, `@Google Drive` 등을 사용하여 내 문서/메일을 직접 검색하고 요약하거나 답장을 초안하는 등의 작업이 가능하다. |
| **데이터 활용** | **시트 내보내기** | 생성된 표 데이터를 클릭 한 번으로 **구글 시트로 즉시 전송**하여 추가 가공이 용이하다. |

### 4. 시각 및 미디어 제작 최적화

*   **고화질 영상 생성 (Veo 3/3.1):** 8초 이상의 고해상도 영상을 생성할 수 있으며, 사운드와 배경 음악이 포함된 완성도 높은 미디어를 제작한다.
*   **이미지 생성 (Imagen 4):** 텍스트 표현력(Typography)과 세부 묘사가 비약적으로 발전한 이미지 생성 기능을 제공한다.
*   **이미지 기반 데이터 추출:** 
    *   사진 속 사물 인식, 텍스트 번역, 수기 글씨를 디지털 텍스트로 변환하는 작업을 수행한다.
    *   메뉴판이나 복잡한 표가 담긴 이미지를 분석하여 데이터 시트로 바로 변환할 수 있다.
*   **잼(Gem) 기능:** 특정 주제나 페르소나를 가진 **나만의 커스텀 AI**를 만들어 반복적인 작업(예: 주간 보고서 작성, 코드 리뷰 등)에 활용할 수 있다.

### 5. 글쓰기 및 콘텐츠 제작 전략

*   **단계별 구조화:** **주제 발굴 → 개요 생성 → 섹션별 초안 작성 → 말투(Tone) 조정**의 단계를 거쳐 품질 높은 콘텐츠를 만든다.
*   **맞춤형 형식 변환:** 동일한 정보를 블로그 포스트, 뉴스레터, 대본, 격식 있는 보고서 등 타겟에 맞는 다양한 형태로 즉시 변환할 수 있다.

### 6. 유의사항

*   **AI 정보의 한계:** AI가 생성한 정보는 '환각 현상(Hallucination)'을 포함할 수 있으므로, 전문적인 법률/의학/금융 정보는 반드시 교차 검증이 필요하다.
