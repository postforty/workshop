# Gemini Gem 실전 예제 (기본 vs APE 개선)

기존의 단순한 요청 방식과 **자동 프롬프트 엔지니어링(APE)** 기법을 활용하여 구체적인 제약 조건을 추가한 개선 방식을 비교해 보세요.

---

## 1. 프롬프트 전문가 Gem
사용자의 모호한 질문을 전문가 수준의 프롬프트로 변환해주는 Gem입니다.

### 🔴 기본 프롬프트
```text
사용자가 입력한 프롬프트를 AI가 최선의 답변을 할 수 있도록 개선하는 프롬프트 전문가 Gem을 만들려고 해. 새로운 Gem을 만들 때 [이름, 설명, 요청 사항]을 입력해야 해. 필요한 내용을 작성해 줘.
```

### 🟢 개선된 프롬프트 (APE 적용)
```text
사용자가 입력한 모호한 프롬프트를 TCREI 또는 CO-STAR 프레임워크를 적용해 최적의 답변을 이끌어내는 '프롬프트 엔지니어링 전문가' Gem을 만들고 싶어. 새로운 Gem을 만들 때 필요한 [이름, 설명, 요청 사항(시스템 프롬프트)]을 작성해 줘. 특히 '요청 사항'은 페르소나와 단계별 개선 로직을 포함해 상세하게 짜줘.
```

---

## 2. 이메일 작성 전문가 Gem
비즈니스 상황에 맞는 이메일을 빠르게 작성해주는 Gem입니다.

### 🔴 기본 프롬프트
```text
이메일 작성 Gem을 만들려고 해. 새로운 Gem을 만들 때 [이름, 설명, 요청 사항]을 입력해야 해. 필요한 내용을 작성해 줘.
```

### 🟢 개선된 프롬프트 (APE 적용)
```text
비즈니스 상황에 맞는 격식 있고 매끄러운 이메일을 작성해 주는 Gem을 만들려고 해. 거절, 요청, 감사 등 다양한 상황을 고려하고, 상대방과의 관계에 따라 톤앤매너를 조절하는 능력을 갖췄으면 좋겠어. 이 Gem의 [이름, 설명, 요청 사항]을 전문가 수준으로 작성해 줘.
```

---

## 3. 지식 기반/사내 가이드 Gem
사내 규정이나 특정 지식 데이터를 기반으로 정확한 답변을 제공하는 Gem입니다.

### 🔴 기본 프롬프트
```text
지식 기반 Gem을 만들려고 해. 새로운 Gem을 만들 때 [이름, 설명, 요청 사항]을 입력해야 해. 필요한 내용을 작성해 줘.
```

### 🟢 개선된 프롬프트 (APE 적용)
```text
우리 회사의 '보안 규정' 및 '업무 가이드'를 완벽히 숙지하고 답변해 주는 사내 챗봇 Gem을 만들려고 해. 사실에 입각해서만 답변하고, 모르는 내용은 추측하지 않고 담당 부서를 안내하도록 설정하고 싶어. 이 Gem의 [이름, 설명, 요청 사항]을 체계적으로 짜줘.
```

---

## 4. 보고서 작성 Gem
업무 보고서나 기획안 초안을 작성해주는 Gem입니다.

### 🔴 기본 프롬프트
```text
보고서 작성 Gem을 만들려고 해. 새로운 Gem을 만들 때 [이름, 설명, 요청 사항]을 입력해야 해. 필요한 내용을 작성해 줘.
```

### 🟢 개선된 프롬프트 (APE 적용)
```text
주간 업무 보고나 신규 사업 기획안의 초안을 작성해주는 '전략 기획 전문가' Gem을 만들고 싶어. 논리적인 구조(개요-현황-문제점-대안-기대효과)를 반드시 갖추고, 데이터 중심의 함축적인 문장을 사용하도록 설정해줘. 이 Gem의 [이름, 설명, 요청 사항]을 작성해 줘.
```
