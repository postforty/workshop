# Obsidian Dataview(데이터뷰) 입문 가이드

**Dataview**는 노트에 저장된 속성(Properties)을 검색하여 자동으로 목록이나 표(Table)로 보여주는 플러그인입니다. 노트를 작성만 하면 **실시간 업무 현황판(대시보드)**이 자동으로 업데이트됩니다.

## 1. 사전 준비

- 이 가이드는 `Dataview` 커뮤니티 플러그인이 설치 및 활성화되어 있어야 작동합니다.
- `Templates` 가이드를 통해 속성이 포함된 문서가 여러 개 생성되어 있어야 효과를 볼 수 있습니다.

## 2. 주요 출력 형식

Dataview는 데이터를 보여주는 방식에 따라 크게 두 가지 형식을 가장 많이 사용합니다.

- **TABLE**: 표 형식. 제목 외에 담당자, 날짜 등 여러 속성을 열(Column)로 추가하여 상세히 보고 싶을 때 사용합니다.
- **LIST**: 목록 형식. 문서의 제목만 심플하게 나열하여 조건에 맞는 문서 리스트를 빠르게 확인하고 싶을 때 사용합니다.

### 기본 문법 구조
Dataview는 마크다운 코드 블럭(```dataview) 내부에 SQL과 유사한 쿼리를 작성합니다.

```sql
[TABLE 또는 LIST] [열 이름(TABLE일 경우)]
FROM "폴더명" 또는 #태그
WHERE [조건]
SORT [정렬기준] [ASC/DESC]
```

## 3. [실습] 실시간 업무 현황판(대시보드) 만들기

특정 폴더에 있는 보고서들을 모아 '상태'와 '담당자'를 한꺼번에 보여주는 현황판을 만들어 봅니다.

### 예시 1: 전체 업무 목록 (표 형식)
상태가 '완료'가 아닌 모든 업무 보고서를 날짜순으로 보여줍니다.

````markdown
```dataview
TABLE 담당자, 상태, 작성일
FROM "ch12"
WHERE 문서구분 = "보고서" AND 상태 != "완료"
SORT 작성일 DESC
```
````

### 예시 2: 상태별 간단 목록 (리스트 형식)
진행 중인 업무의 제목만 나열합니다.

````markdown
```dataview
LIST
FROM "ch12"
WHERE 상태 = "진행중"
```
````

## 4. 입문자를 위한 활용 시나리오

1.  **할 일(To-do) 관리**: `마감일` 속성을 추가하고 `WHERE 마감일 < date(today)` 쿼리를 사용하면 오늘까지 끝내야 할 연체 업무만 따로 모아볼 수 있습니다.
2.  **공유 대시보드**: 팀 공용 폴더 내의 노트들을 Dataview로 집계하면, 누가 어떤 일을 하고 있는지 보고 없이도 실시간으로 파악됩니다.

## 5. 결과가 나오지 않나요? (No results to show)

만약 "No results to show"라는 메시지가 뜬다면 아래 두 가지를 확인해 보세요.

1.  **실제 문서가 있는지 확인**: 템플릿을 사용하여 `상태: 진행중` 또는 `문서구분: 보고서` 속성이 입력된 문서를 최소 1개 이상 생성했는지 확인하세요.
2.  **폴더 경로 확인**: 보관함(Vault) 구조에 따라 경로를 수정해야 할 수 있습니다.
    - 만약 `ch12`가 최상위 폴더가 아니라면 전체 경로를 적어주어야 합니다. (예: `FROM "ax_poongsan_260122/ch12"`)
    - 폴더 경로 대신 `#태그`를 사용하면 경로와 상관없이 데이터를 가져올 수 있습니다. (예: `FROM #보고서`)

## 6. 주의 사항

- **값의 정확성**: 속성 값에 오타가 있으면(예: '완료' 대신 '완룟') 검색 결과에서 누락됩니다.
- **대소문자 및 띄어쓰기**: `상태:진행중`과 `상태: 진행중`은 다를 수 있으므로 템플릿을 통한 일관된 입력이 중요합니다.
- **리스트 형식 주의**: 만약 속성 값 앞에 점(•)이 생긴다면 해당 속성이 '텍스트'가 아닌 '리스트' 형식인 것입니다. 이 경우 `상태 != "완료"` 대신 `!contains(상태, "완료")`를 사용해야 정확히 필터링됩니다.
- **실시간성**: 노트를 수정하고 저장하는 즉시 Dataview 결과에 반영됩니다.
