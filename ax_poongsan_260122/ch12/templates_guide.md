# Obsidian Templates(템플릿) 입문 가이드

**Templates**는 자주 사용하는 문서 양식(보고서, 회의록, 업무 일지 등)을 미리 정의해 두고 필요할 때마다 즉시 불러오는 기능입니다. 업무 양식을 통일하면 정보 누락이 방지되고, 검색 및 자동화(Dataview)가 훨씬 쉬워집니다.

## 1. 사전 설정 (최초 1회)

템플릿 기능을 사용하기 위해 Obsidian 설정을 먼저 확인해야 합니다.

1.  보관함(Vault)에 `Templates` 폴더를 생성합니다.
2.  `Settings` (Ctrl + ,) -> `Core plugins` -> `Templates` 활성화 확인.
3.  `Settings` -> `Templates` 옵션에서 `Template folder location`을 방금 만든 `Templates` 폴더로 지정합니다.

## 2. [실습] 표준 업무 보고서 템플릿 만들기

가장 기본적인 '업무 보고서' 양식을 템플릿으로 등록해 보겠습니다.

### 1단계: 템플릿 파일 생성
- `Templates` 폴더 안에 `표준 업무 보고서.md` 파일을 만듭니다.

### 2단계: 내용 작성 (속성 포함)
- 파일 최상단에 속성(Properties)을 포함한 내용을 아래와 같이 작성합니다.
- `{{date}}`나 `{{title}}` 같은 변수를 사용하면 문서를 불러올 때 자동으로 오늘 날짜와 파일 이름이 입력됩니다.

```markdown
---
문서구분: 보고서
상태: 대기
담당자: 
작성일: {{date}}
---

# {{title}} 업무 보고

## 1. 진행 내용
- (내용을 입력하세요)

## 2. 향후 계획
- (내용을 입력하세요)

## 3. 애로 사항
- (내용을 입력하세요)
```

## 3. 템플릿 사용하기

1.  새 노트를 생성합니다 (예: `260127_품질분석보고`).
2.  명령어 팔레트에서 `Insert template`을 누릅니다.
3.  목록에서 `표준 업무 보고서`를 선택합니다.
4.  지정된 양식과 오늘 날짜가 자동으로 입력되는 것을 확인합니다.

---

## 4. 실습 팁
- **속성의 중요성**: 템플릿에 `상태`, `담당자` 같은 속성을 미리 넣어두어야 나중에 **Dataview**를 이용해 업무 현황판을 자동으로 만들 수 있습니다.
- **날짜 형식**: `{{date:YYYY-MM-DD}}` 처럼 형식을 직접 지정할 수도 있습니다.
