# Properties (속성) 기반 검색 매뉴얼

Obsidian의 **속성** (Properties)은 노트의 최상단에 위치하며, 제목, 날짜, 태그, 상태 등 노트에 대한 정형화된 메타데이터를 저장하는 공간입니다. 이를 활용하면 단순한 단어 검색을 넘어, 특정 조건을 만족하는 데이터를 정확하게 찾아낼 수 있습니다.

## 1. 속성 추가 및 설정

노트 상단에 속성을 추가하는 방법은 다음과 같습니다.

- **단축키 활용**: `Ctrl + ;` (Windows 기준)를 누르면 속성 입력을 위한 인터페이스가 활성화됩니다.
- **직접 입력**: 노트의 가장 첫 줄에 `---`를 입력하고 다음 줄에 속성 정보를 넣은 뒤 다시 `---`로 닫으면 YAML 형식의 속성이 생성됩니다.
- **주요 속성 유형**:
  - **텍스트 (Text)**: 단순 문자열 (예: 작성자, 프로젝트명)
  - **리스트 (List)**: 여러 개의 값 (예: 카테고리, 관련인물)
  - **날짜 (Date)**: 달력 형식의 날짜 (예: 마감일, 생성일)
  - **체크박스 (Checkbox)**: 참/거짓 상태 (예: 완료여부)

## 2. 기본 속성 검색 (검색창 이용)

Obsidian 왼쪽 사이드바의 검색창(`Ctrl + Shift + F`)에서 대괄호 `[]`를 사용하여 속성 기반 검색을 수행합니다.

| 검색 유형 | 검색 문법 예시 | 설명 |
| :--- | :--- | :--- |
| **속성 존재 여부** | `[status]` | `status`라는 속성이 포함된 모든 노트를 검색합니다. |
| **정확한 값 일치** | `[status:진행중]` | `status`의 값이 '진행중'인 노트를 검색합니다. |
| **공백 포함 이름** | `["Due Date":2026-01-26]` | 속성 이름에 공백이 있으면 큰따옴표 `""`로 감쌉니다. |
| **빈 속성 찾기** | `[project:null]` 또는 `[project: ]` | `project` 속성은 있지만 값이 비어있는 노트를 검색합니다. |

## 3. 고급 검색 연산자 활용

속성 검색은 다른 검색 예약어와 조합하여 더 정교하게 필터링할 수 있습니다.

- **숫자 및 날짜 비교 (범위 검색)**:
  - `[priority: >2]` : 중요도가 2보다 큰 노트를 검색합니다.
  - `[created: 2026-01]` : 2026년 1월에 생성된 모든 노트를 검색합니다.
- **논리 연산 조합 (AND, OR, NOT)**:
  - `[type:회의] [status:완료]` : 타입이 회의이고 상태가 완료인 노트 (AND)
  - `([status:대기] OR [status:진행중])` : 상태가 대기 또는 진행중인 노트 (OR)
  - `-[status:완료]` : 상태가 완료인 노트를 검색 결과에서 제외 (NOT)

## 4. 실전 활용 예시

| 활용 시나리오 | 검색 명령어 예시 |
| :--- | :--- |
| **미완료 업무 확인** | `path:Project [status:대기] -tag:#보류` <br> (Project 폴더 내, 대기 상태이며 #보류 태그가 없는 문서) |
| **특정 기간 보고서** | `[type:보고서] [date: 2024-01-01 .. 2024-12-31]` <br> (타입이 보고서이고 2024년 내에 작성된 문서) |
| **특정 담당자 업무** | `[assignee:홍길동] [status:진행중]` <br> (담당자가 홍길동이고 현재 진행 중인 업무) |

## 5. 권장 속성 키워드 가이드

데이터를 정형화하고 효율적으로 관리하기 위해 시스템이 예약한 키워드와 실무에서 관례적으로 사용하는 키워드를 구분하여 사용하는 것이 좋습니다.

### 5.1 Obsidian 시스템 예약 속성
이 키워드들은 Obsidian 프로그램 내부 기능을 수행하기 위해 미리 정의된 이름입니다.

| 속성명 | 기능 | 사용 예시 |
| :--- | :--- | :--- |
| `tags` | 노트에 태그를 추가 (해시태그 `#` 기호 없이 입력) | `tags: [회의, 스마트팩토리]` |
| `aliases` | 문서의 별칭 설정 (다른 이름으로도 링크/검색 가능) | `aliases: [PS-Project, 교육안]` |
| `cssclasses` | 해당 노트에만 특정 CSS 디자인을 적용 | `cssclasses: [dashboard, cards]` |

### 5.2 실무 권장 키워드 (표준/한글 조합)
조직 내에서 키워드를 통일하면 자동화 시스템 구축 시 데이터 누락을 방지할 수 있습니다.

| 분류 | 영문 키워드 | 한글 키워드 | 활용 예시(값) |
| :--- | :--- | :--- | :--- |
| **현황** | `status` | `상태` | 대기, 진행중, 완료, 보류 |
| **종류** | `type` | `문서구분` | 회의록, 보고서, 지침, 기획서 |
| **날짜** | `created`, `due` | `작성일`, `기한` | 2026-01-27 |
| **사람** | `assignee` | `담당자` | 홍길동, 생산기술팀 |
| **연관** | `project` | `프로젝트` | 풍산_AI_자동화 |
| **중요도** | `priority` | `우선순위` | 상, 중, 하 |

## 6. 팁 (Tips)

- **소문자 사용 권장**: 데이터 추출 도구(Dataview 등)와의 호환성을 위해 속성 이름은 가급적 **소문자**로 통일합니다.
- **공백 관리**: `due_date`와 같이 언더바(`_`)를 사용하여 공백을 관리하면 검색 시 편리합니다.
- **검색 저장**: 자주 사용하는 속성 검색 쿼리는 검색창의 '검색 저장 (Star)' 기능을 활용하세요.
- **데이터베이스화**: 속성 기반 검색에 익숙해지면, 나중에 **Dataview** 플러그인을 통해 실시간 현황판을 대시보드 형태로 구성할 수 있습니다.
